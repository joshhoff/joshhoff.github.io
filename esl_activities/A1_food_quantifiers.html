Understanding Quantifiers

Countable Nouns

Things we can count (1, 2, 3...)

A / An

For one item

Example: an apple, a banana

A Few

A small number (positive)

Example: I have a few apples.

Many

A large number

Example: There are many vegetables.

Some

An unspecified amount

Example: I bought some oranges.

Uncountable Nouns

Things we cannot count individually

A Little

A small amount (positive)

Example: I need a little water.

Much

A large amount

Example: There isn't much milk left.

Some

An unspecified amount

Example: Would you like some rice?

Any

Used in questions and negatives

Example: Do you have any juice?
