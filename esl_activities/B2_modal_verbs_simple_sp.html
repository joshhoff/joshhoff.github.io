🧠 Memory Trick: The Certainty Scale

might → may → could → can → should → will → must

Less certain ←――――――――――――→ More certain

Think of it like a thermometer—the "hotter" the modal, the more certain you are!

🇪🇸 Spanish Speaker Pitfalls

  • ❌ Common Error: "I must to go" (Debo ir)
    ✅ Correct: "I must go" — No "to" after modals!
  • ❌ Common Error: "She cans swim"
    ✅ Correct: "She can swim" — No conjugation!
  • ❌ Common Error: Using "can" for polite requests
    ✅ Better: "Could/May I...?" — More formal than "¿Puedo...?"

⚡ Quick Rules to Remember

Rule 1: Modal + base verb (no "to")
I can swim ✅ NOT I can to swim ❌
Rule 2: No -s for he/she/it
She can ✅ NOT She cans ❌
Rule 3: Questions = Modal first
Can you help? ✅ (Like Spanish: ¿Puedes ayudar?)
Rule 4: Negatives = Modal + not
You should not / shouldn't go

🎯 Context Matters!

The same modal can mean different things:

"Can"
Ability: I can speak Spanish. (Puedo/Sé hablar español)
Permission: You can leave now. (Puedes irte)
Possibility: It can rain. (Puede llover)
"Should"
Advice: You should study. (Deberías estudiar)
Expectation: He should arrive soon. (Debería llegar pronto)
