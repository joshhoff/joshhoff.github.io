Weather Verbs

Common verbs used to talk about the weather

English Spanish Example
to rain llover It is raining. Está lloviendo.
to snow nevar It is snowing. Está nevando.
to shine brillar The sun is shining. El sol está brillando.
to freeze congelar It is freezing outside. Está helando afuera.
to blow soplar The wind is blowing. El viento está soplando.
to thunder tronar It is thundering. Está tronando.

Weather Phrases

Useful phrases to talk about the weather

🌤️

How's the weather?

¿Cómo está el clima?

Use this to ask about the current weather.

☀️

It's a beautiful day!

¡Es un día hermoso!

Use this when the weather is nice.

🌧️

It's raining cats and dogs!

¡Está lloviendo a cántaros!

An expression for heavy rain.

🥶

It's freezing outside!

¡Hace mucho frío afuera!

Use this when it's very cold.

🌡️

What's the temperature today?

¿Cuál es la temperatura hoy?

Ask about the specific temperature.

🔮

What's the forecast for tomorrow?

¿Cuál es el pronóstico para mañana?

Ask about future weather conditions.
